# Ribbon heart app icon

The current app icon keeps the pink, coral, orange and blush ribbon-heart treatment of the [Love Logo reference by Masuder Rahaman](https://dribbble.com/shots/20054258-Love-Logo), with two outer ribbon curls instead of three.

- Source: `ribbon-heart-master.png` (1254 × 1254), generated with the built-in imagegen tool.
- In-app header and sign-in logo: load this named master directly, independently of the launcher icon. The web dashboard and favicon import the same file as a content-hashed, bundled asset; the legacy `/fieldops-mark.svg` URL redirects to it.
- Mobile icon: `../icon.png` (1024 × 1024, opaque).
- Android adaptive foreground: `../adaptive-icon.png` (1024 × 1024, with extra inset to accommodate launcher masks).
- Native iOS, Android density variants, and the 512 × 512 store icon are generated by `node scripts/generate-app-icons.mjs` from the repository root.
- `app-icon-previous.svg` preserves the previous icon source.

## Generation prompt

Use case: precise-object-edit / logo-brand.
Asset type: production mobile app icon, square 1024 by 1024 pixels.
Input image 1 is the edit target/reference: the pink and orange heart wrapped in silky pink ribbons from the supplied Dribbble design.
Primary request: recreate this same heart-and-ribbon logo with ONE subtle design change: reduce the three outward curling ribbon returns on the right to TWO broader, flowing curls. Preserve the heart's two rounded top lobes, pointed bottom, broad pink ribbon sweeping across the front, warm coral-to-orange top surface, delicate rose pink edges, pale blush highlights, softly shaded satin ribbon folds and overall proportions. Keep it extremely close to the visual language of the reference. The changed ribbon count should be clearly visible while the heart remains immediately recognizable.
Composition: one centered logo on a uniform very pale warm gray background (#F7F7F7) that fills the entire square canvas edge to edge. The complete heart plus its right curls occupies about 68 percent of the canvas width and 60 percent of the height, centered optically, with comfortable margin for app icon masking. Sharp, clean, professionally finished contours and smooth gradients.
Constraints: exactly one finished icon. No wordmark, letters, caption, border, outer rounded-square shape, grid, sample sizes, device mockup, watermark, cast shadow on the background, or additional symbols. Keep the icon background opaque. Do not transform it into a leaf, location pin, rice grain or letter; it must stay a heart.
